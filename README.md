Mini Quiz App

Project Overview

The Mini Quiz App is an interactive web application that allows users to take a multiple-choice quiz, receive immediate feedback on their answers, and view their final score at the end. This project is designed to showcase beginner-level web development skills, including HTML, CSS, and JavaScript, and demonstrates logic implementation, DOM manipulation, and responsive design.

Features
* 5–10 multiple-choice questions
* Highlights correct and incorrect answers immediately
* Calculates and displays final score
* Responsive layout for desktop and mobile devices
* Clean and user-friendly interface

Tech Stack
* HTML – Structure of the quiz interface
* CSS – Styling and responsive layout
* JavaScript – Question logic, scoring, and interactivity
